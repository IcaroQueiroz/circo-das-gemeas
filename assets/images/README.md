- Tema: Circo Rosa Candy Color

## Estrutura das pastas

- `characters/`: Liz e Luna em diferentes poses.
- `circus/`: elementos principais do universo circense, como logo, tenda, carrossel e placas.
- `decorations/`: balões, nuvens, cortinas, bandeirolas, confetes, estrelas, corações e faixas decorativas.
- `ui/`: molduras e elementos que podem ser usados diretamente na interface ou em cards.
- `backgrounds/`: reservado para cenários/backgrounds reais. Nenhum asset atual foi classificado aqui.
- `reference/`: reservado para imagens de referência que não aparecem no site. Nenhum asset atual foi classificado aqui.
